# M4 — Normal-Mapped 2.5D Lighting

**Status:** ✅ done · **Goal:** point + directional lights, **each with a height above the sprite
plane**, per-pixel diffuse (N·L) + specular + ambient, with sampled normals **rotated by the
sprite's rotation** so lighting stays world-consistent as ships turn (brief §6.7).

## Decisions locked

| Decision | Choice |
|---|---|
| Shaders | **Defer shadercross again.** Hand-compile `lit_sprite.hlsl` → DXIL; device stays DXIL-only. The HLSL follows SDL_GPU conventions so shadercross consumes it unchanged later. |
| Model | Diffuse N·L + **Blinn-Phong** specular + ambient. Point + directional, each with height `z`. |
| Architecture | **Single-pass forward**, one lit pipeline for all sprites (sprites without normals get a flat fallback). Forward fits: < 16 lights, flat geometry, alpha-blended sprites. |
| Lights | ECS entities (`Transform` + `Light`), packed into a 16-light fragment UBO at **render time** (not in the sim). |
| Normal maps | Procedural placeholder bevel maps `*_normal.png`, generated by `tools/gen_normals.ps1`. |
| Out of scope | Shadows, deferred rendering, linear/sRGB management, shadercross. |

## Design

- **Shader:** vertex forwards world pos + `(cos, sin)`; fragment unpacks the normal, rotates `n.xy` by
  the **same** `(c, s)` the CPU baked into positions, lights in world space with `V = (0,0,1)`.
- **`render/LightsUBO.hpp`:** byte-matched to the HLSL cbuffer (`static_assert`).
- **`systems/LightingSystem::collect_lights`:** render-time packing, cap 16.
- **Renderer:** vertex gains `(cos, sin)`; `draw()` takes albedo + normal; one draw per
  `(albedo, normal)` run with two samplers; 1×1 flat-normal fallback always bound.
- **Data:** optional `normal` paths in ship/wall defs; `"lights"` array in levels; ImGui debug light +
  Lighting panel.

## Sub-steps (each verified visually)

1. Vertex format + pass-through lit pipeline (scene identical to M3). 2. Ambient only.
3. One point light, flat normals (height falloff). 4. Normal maps + specular.
5. **Rotate normals by sprite rotation** (spin the ship under a fixed light: same world side
stays lit). 6. Directional + multiple lights. 7. ImGui lighting panel.

## Risks called out

Normal-rotation sign (rotate by the same `(c, s)`, not the inverse) · one green-channel convention
fixed in one place · normal maps never sRGB · don't light alpha · both samplers always bound · UBO
layout drift · lights stay out of the fixed-step loop.

## Outcome

Delivered. Post-M4 fixes requested and done before M5:
1. **Void is unlit**: per-vertex `emissive` flag; unlit sprites return albedo untouched.
2. **Void is one background**: `Level` dropped void rects; floor = union of rects, void = gaps,
   one camera-locked unlit backdrop (`background.png`), parallax-ready.
3. **Elastic camera follow, translate only**: `render/CameraFollow.hpp` with swappable
   `SmoothDampFollow` (default) and `ExponentialFollow`, tunable in a Camera panel.
4. **Polygon hitboxes**: ship collision uses its convex polygon from JSON; SAT narrow phase.
